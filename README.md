# JARVIS

A custom interactive new-tab dashboard built with HTML, CSS, and JavaScript.

## Features

- JARVIS-themed custom interface
- Live clock
- Interactive command system
- Voice input
- Basic browser commands
- NASA Astronomy Picture of the Day API
- Responsive design for mobile and desktop

## Tech Stack

- HTML
- CSS
- JavaScript
- Vite
- NASA APOD API

## How to Run

```bash
npm install
npm run dev
